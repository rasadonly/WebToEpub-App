How to Convert Web Novels to EPUB

LinkToEpub turns a web novel into a clean EPUB file you can read on any ebook app. The whole process is: paste a link, fetch the chapters, generate the file.

Start Converting →

1. Convert a novel by URL

  1. Open the novel’s main page on the source site — the page with the synopsis and the chapter list, not a chapter or reader page. Good URLs look like allnovelfull.com/the-beginning-after-the-end.html.
  2. Copy that URL and paste it into the search bar on the home page. The book’s title, author, and cover load automatically — fix anything that looks wrong before you continue.
  3. Click Fetch Chapters. The chapter list loads with a progress bar. Very long novels can take a few minutes; that is normal.
  4. Pick your chapters. By default everything is selected. Under Show advanced options you can set a Start and End Chapter instead — handy for splitting a huge novel into volumes.
  5. Click Generate EPUB. The file is built on the server.
  6. Download the EPUB when it is ready. Generated files stay on the server for 6 hours, so grab yours the same day.

2. No URL? Search by novel name

Type the novel’s name into the same search bar instead of a URL. Results come back from across the supported sites — pick the right one and it fills in the link for you, then continue from Fetch Chapters as above.

3. Tune the result (advanced options)

Under Show advanced options you can change the book’s metadata (title, author, language), pick a font for the EPUB, choose which site’s layout to use, and set custom CSS selectors for the chapter list and chapter text. The selectors are the fix when a site fetches but the content comes out empty or wrong.

4. Read it

Open the downloaded EPUB in any ebook app — Kindle, Kobo, Apple Books, Moon+ Reader, or anything else that reads EPUB. You can also open it in the built-in EPUB Reader from the menu, without leaving the site.

5. Skip converting: the Community Library and Forum

Thousands of novels are already converted. In the Library you can download ready-made EPUBs straight from the Community collection, plus the Archive.org collection — no converting needed. Your own downloads live under My Books.

The Forum is where the community helps out: report a site that fails, request a new site, or request a book you cannot find — another reader can upload the EPUB for you and you get thanked by name in the thread.

6. When something goes wrong

  • Fetch fails, or only a few chapters show. Almost always this means you pasted a chapter URL instead of the novel’s main page. Go back to the main page and copy that URL.
  • A site fails every time. It may be blocking automated access. Report it in the Forum with the URL so it can be looked at.
  • Chapters fetch but the text is empty or wrong. Try custom selectors under Advanced options for that site’s layout.
  • Your site is not in the 650+ list. Paste the URL anyway — the AI fallback handles most novel sites automatically.
  • Only recent chapters appear. Some sites list only the latest chapters on their main page. If the site has a full chapter list page, use that URL instead.
